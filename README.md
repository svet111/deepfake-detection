
# Deepfake Detection

A binary image classification pipeline built with TensorFlow and Keras to distinguish between real and manipulated (deepfake) face images using transfer learning and fine-tuning on ResNet50.

## Results

Evaluated on the unseen test split (307 images from `ciplab/real-and-fake-face-detection`):

- **Initial Baseline (Frozen ResNet50):** 54% test accuracy
- **Fine-Tuned Model (Top 15 layers unfrozen, `lr=1e-5`):** 62% test accuracy

| Class | Precision | Recall | F1-Score | Support |
| :--- | :---: | :---: | :---: | :---: |
| Fake | 0.59 | 0.58 | 0.58 | 144 |
| Real | 0.63 | 0.65 | 0.64 | 163 |

## Setup and Installation

1. Clone the repository and navigate into the project directory:
```bash
git clone [https://github.com/svet111/deepfake-detection.git](https://github.com/svet111/deepfake-detection.git)
cd deepfake-detection
```


2. Create a virtual environment and install dependencies:
```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```



## Usage

### 1. Prepare the Dataset

Download the `ciplab/real-and-fake-face-detection` dataset (~430 MB) via `kagglehub` and organize the images into `data/train` (70%), `data/val` (15%), and `data/test` (15%) to prevent data leakage:

```bash
python prepare_data.py
```

### 2. Train the Model

Train the fine-tuned ResNet50 classifier and save the weights to `models/deepfake_detector.h5`:

```bash
python train.py
```

*Note: `steps_per_epoch` is capped at `200` and `validation_steps` at `50` so training completes efficiently on a CPU. Increase or remove these caps if training on a GPU or a larger dataset.*

### 3. Evaluate on the Test Set

Run evaluation on the unseen `data/test` split to generate a classification report and confusion matrix:

```bash
python evaluate.py
```

### 4. Predict on a Single Image

Classify an individual face image and print the predicted label and confidence score:

```bash
python predict.py path/to/image.jpg
```

## Model Details

* **Backbone:** ResNet50 (ImageNet weights) with the top 15 layers unfrozen for fine-tuning.
* **Classifier Head:** Global Average Pooling, Dense (128 units, ReLU), Dropout (0.5), and a single Sigmoid output (`0` = Fake, `1` = Real).
* **Training Configuration:** Adam optimizer (`learning_rate=1e-5`), binary cross-entropy loss, and `resnet50.preprocess_input` pixel scaling.

## Future Improvements

- **Larger Datasets:** Train on larger image datasets (such as `140k-real-and-fake-faces`) or extract cropped face frames from video benchmarks like FaceForensics++ and Celeb-DF to improve generalization.
- **Full Fine-Tuning on GPU:** Unfreeze more trainable parameters across `ResNet50` (or experiment with `EfficientNet`), remove the CPU `steps_per_epoch` cap, and train for additional epochs with early stopping.
- **Configurable Decision Threshold:** Add a command-line threshold flag in `predict.py` to tune the balance between false positives and false negatives depending on the use case.
